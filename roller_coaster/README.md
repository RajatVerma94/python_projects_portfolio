# Roller Coaster Height Checker

A beginner Python program that checks whether a person is tall enough 
to ride a roller coaster and calculates their ticket price based on age.

## What it does

- Asks the user for their height in centimeters
- If they meet the minimum height (120 cm), asks for their age
- Calculates ticket price based on age bracket:
  - Under 18: $7
  - 18 and above: $12
- Prints the final ticket price

## How to run it

1. Make sure you have Python 3 installed
2. Open a terminal in this folder
3. Run: `task.py`
4. Follow the prompts
